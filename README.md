# mission3 - 작은 계산기(Mini NPU 시뮬레이터)

3주차 미션. AI가 하는 MAC(곱하고 더하는) 연산을 파이썬으로 직접 구현하는 과제.
현재 **진행 중**이며, 아래 표는 2026-11-20 기준 상태임.

## 환경
| 항목 | 내용 |
|---|---|
| OS | Windows 11 |
| Python | 3.14.10 |
| 편집기 | VS Code |
| 외부 라이브러리 | 사용 안 함 |

## 진행 상태
| 기능 | 상태 |
|---|---|
| MAC 연산 함수 `mac(pattern, filter_)` | 구현 |
| 두 점수 비교로 Cross / X / UNDECIDED 판정 | 구현 (동점은 UNDECIDED, epsilon 비교는 미적용) |
| 모드1: 3×3 필터·패턴 키보드 입력과 검증 | 미구현 |
| 모드2: data.json 읽기, 라벨 정규화, PASS/FAIL | 미구현 |
| 성능 분석 (크기별 10회 평균 ms 표) | 미구현 |
| 결과 리포트 (실패 원인, 시간 복잡도) | 미구현 |

## 파일 구조
| 파일 | 설명 |
|---|---|
| `main.py` | 미션 코드는 40~69번 줄(`mac` 함수와 판정). 나머지는 학습 중 연습한 코드 |
| `test.py` | `input` 연습용 |

## 실행 결과 (구현한 부분)
`main.py`의 `mac` 판정 부분을 실행해 확인함. 패턴은 십자가 모양임.

| 계산 | 결과 |
|---|---|
| 패턴 × 십자가 필터 | 5 |
| 패턴 × X 필터 | 1 |
| 판정 | Cross |

손계산(같은 자리 칸이 둘 다 1인 개수)으로도 십자가 필터 5, X 필터 1이 나옴.
